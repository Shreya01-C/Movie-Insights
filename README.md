# 🎬 MovieInsight

MovieInsight is a modern web application that helps users explore movies, view details, and discover trending, popular, and top‑rated films. It provides a clean interface, dynamic searches for cast, and recommendations.

---

## 🌐 Live Demo
🔗[MovieInsight on Netlify](https://silly-faloodeh-220392.netlify.app/)  

---

## ✨ Features
-  **Search Movies** — Find movies by title and explore detailed information.
-  **Movie Details** — View synopsis, cast, trailers, and ratings.
-  **Trending & Popular** — Browse trending, popular, and top‑rated movies.
-  **Dynamic UI** — Responsive design with reusable components.
-  **Fast Performance** — Optimized with React and modern tooling.

---

## 🛠️ Tech Stack
- **Frontend**: React, SCSS
- **State Management**: Redux Toolkit
- **API**: TMDb (The Movie Database API)
- **Deployment**: Netlify

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or above)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Shreya01-C/Movie-Insights.git

# Navigate into the project
cd MovieInsight

# Install dependencies
npm install

# Start the development server
npm start
```
